
# IEUM Studio

**Ideas Become Reality.**

IEUM Studio is an interactive creative technology studio concept exploring AI, software, design and security.

## Features

- Responsive landing page
- Korean / English UI toggle
- Rule-based AI response simulator
- Sandboxed HTML playground
- Educational phishing-awareness quiz
- Interactive brand color and slogan preview
- Random project idea generator
- Local exploration checklist and badges
- Local design and progress storage
- No external JavaScript libraries

## Run locally

Open `index.html` in a modern browser.

## Deploy with GitHub Pages

1. Create a GitHub repository named `ieum-studio`.
2. Upload `index.html`, `styles.css`, `app.js`, `favicon.svg` and `README.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for the deployment URL.

## Deploy with Vercel

Import the GitHub repository into Vercel.
No build command or output directory is required for this static site.

## Privacy

Demo interactions run in the browser. Exploration progress and saved brand designs use localStorage on the current device.

## Important limitations

The AI lab is a rule-based simulation, not a real AI model.
Project cards marked CONCEPT describe concepts, not claims of completed products.
The project suggestion contact address must be configured before email submission can work.
