MORE THAN A WEBSITE

웹사이트 하나가 아니라,
가능성을 실험하는 놀이터.

새로운 서비스를 기획할 때도, 코드를 작성할 때도, 디자인을 바꿀 때도 중요한 건 직접 시도해 보는 거야. IEUM Playground는 그런 시도를 더 쉽고 재미있게 만드는 공간이야.

완벽한 결과물만 보여 주기보다 아이디어가 어떻게 발전하는지, 어떤 선택을 할 수 있는지, 무엇을 배울 수 있는지를 중요하게 생각해.

CORE VALUES

다섯 가지 핵심 가치

IEUM을 만들어 가는 데 중요하게 생각하는 원칙이야.

💡
01 / IDEA

호기심

당연해 보이는 것도 질문하고, 아직 답이 없는 문제를 새로운 관점에서 바라봐.

🛠️
02 / BUILD

실행

아이디어를 머릿속에만 두지 않고 작더라도 직접 작동하는 결과물로 만들어 봐.

🔗
03 / CONNECT

연결

서로 다른 지식과 도구를 연결해서 혼자서는 생각하지 못했던 가능성을 찾아.

🔐
04 / SECURITY

보안

편리함뿐 아니라 개인정보 보호와 안전한 설계를 처음부터 고려해.

♻️
05 / IMPROVE

개선

첫 결과물이 완벽할 필요는 없어. 테스트하고 고치면서 더 나은 결과를 만들어.

HOW WE THINK

IEUM의 개발 철학

기능을 많이 넣는 것만큼, 제대로 작동하도록 만드는 것도 중요해.

01

사용자가 먼저

멋진 기술이라도 사용하기 어렵다면 다시 생각해 봐. 누구나 이해하고 사용할 수 있는 경험을 목표로 해.

◎
02

필요한 만큼 가볍게

불필요한 리소스 사용을 줄이고, 가능한 한 다양한 기기에서 원활하게 작동하도록 설계해.

◈
03

보안은 나중이 아니라 처음부터

API 키와 비밀 정보는 공개 프런트엔드에 넣지 않고, 필요한 권한만 부여하는 구조를 지향해.

⌑
04

직접 검증하기

코드가 작성됐다는 사실과 기능이 정상적으로 작동한다는 사실은 달라. 실제 실행과 테스트로 확인해.

✓
05

작은 시작에서 확장하기

처음부터 모든 기능을 한꺼번에 만들기보다, 핵심 기능을 안정적으로 만든 뒤 단계적으로 확장해.
